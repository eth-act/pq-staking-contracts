# Site

Placeholder for a website explaining how the staking and registration contracts work.

Contract data to build from:

- `../contracts/dist/bytecode.json`: ABIs, creation and runtime bytecode, and compiler settings
  for every contract. Generate it with `cd ../contracts && ./scripts/export-bytecode.sh`.
- The same file is attached to every [GitHub release](https://github.com/eth-act/pq-staking-contracts/releases)
  if the site should show released versions only.

Changes here do not trigger contract releases.
